# Working on geoscales

Nested regions and spatial hierarchies for modeling — the spatial companion to
`timescales`, part of the optimal2050 stack. Phase 1 is a pure-R implementation
(`cpp/`, `python/` are placeholders for later phases).

Stack-wide rules (naming, style, git policy, API principles) live in the
unified conventions document: `optimal2050/.github/CONVENTIONS.md`
(https://github.com/optimal2050/.github/blob/main/CONVENTIONS.md).
Everything below is repo-specific — things you would otherwise discover
the hard way.

## Layout

| Path | What it is |
|---|---|
| `R/` | package source (~4k lines). `geoscale-class.R` defines the S7 class; `map.R` the crosswalk + registry, `backend.R` the df/dt/dtplyr/arrow contract, `ggplot-layers.R` the composable `geom_geoscale()`/`theme_geoscale()` |
| `tests/testthat/` | eleven test files, mirroring the R sources |
| `pkgdown/` | `extra.scss` (dark-mode figure-inversion opt-out) + favicons -- do not delete |
| `vignettes/` | shipped vignettes (`geoscales`, `from-naturalearth`) |
| `vignettes/articles/` | pkgdown-only articles — **not shipped**, see below |
| `man/`, `NAMESPACE` | generated by roxygen — **never edit by hand** |
| `docs/` | pkgdown build output — **never edit by hand** |
| `drafts/` | archived removed code — **do not edit, do not source** |
| `specs/`, `cpp/`, `python/`, `benchmark/` | placeholder READMEs for later phases |

There is no `data/` and no `data-raw/`: the package ships integration code, not
data. Keep it that way.

## Build and test

```r
devtools::load_all()
devtools::document()      # roxygen 8.0.0, pinned in DESCRIPTION
devtools::test()
```

For a full check, note that **`R` is an alias for `Invoke-History` in
PowerShell** — `R CMD build` fails with "positional parameter cannot be found".
Use the interpreter's real path:

```powershell
$RBIN = (Rscript -e "cat(file.path(R.home('bin'),'R.exe'))")
& $RBIN CMD build .
& $RBIN CMD check geoscales_<version>.tar.gz --no-manual
```

`R CMD check` is currently clean (Status: OK, no NOTEs). Keep it that way.

## Hard rules

**Never add `energyRt` as a dependency.** `energyRt` suggests `geoscales`; a
dependency in the other direction closes a loop. This is why
`vignettes/articles/plotting.Rmd`, which draws on UTOPIA maps from `energyRt`,
is a pkgdown-only article listed in `.Rbuildignore` as `^vignettes/articles$` —
`R CMD build` never ships it, so `R CMD check` never sees its `energyRt::`
calls. The check *does* flag `::` on undeclared packages in vignettes
(`tools:::.check_packages_used_helper` matches `::` explicitly), so moving that
file back into `vignettes/` would immediately cost a NOTE. `energyRt` belongs in
`Config/Needs/website` only.

**Don't delete code — move it to `drafts/<topic>/`**, with a README recording
what it did, what was touched, and how to restore it. `^drafts$` is in
`.Rbuildignore`. See `drafts/ne-pov/` for the shape.

**Licences differ.** `geoscales` is Apache-2.0; `energyRt` is AGPL-3. Do not
copy code or data between them without an explicit decision from the maintainer.

**The package ships no maps and selects no boundaries.** That is a stated
design position, not an oversight.

## Package conventions

- **S7, not S4 or R6.** A `Geoscale` holds `leaftable`, `geoframes`, `members`,
  optional `geometry` and `meta`. Everything derivable — parent/child tables,
  ancestry, shares, level ranks — is computed on demand. Nothing is cached on
  the object.
- **`.onLoad()` in `R/zzz.R` is load-bearing.** `S7::methods_register()` must
  run or `print(gs)` falls through to the default and dumps raw properties (an
  S7 object is not S4-backed, so `isS4()` is `FALSE`). It also registers the
  built-in providers and, only when ggplot2 is present, the `autoplot` S3
  method.
- **`sf`, `ggplot2`, `rnaturalearth` are all Suggests** — the core is
  geometry-free. Guard every use with `requireNamespace()` and a helpful error
  naming the install command. `rnaturalearthhires` is **not on CRAN**; it comes
  from <https://ropensci.r-universe.dev>.
- **lintr**: 80-column lines. `object_name_linter`, `indentation_linter` and
  `commented_code_linter` are disabled deliberately — see `.lintr` for why.
  CI runs lint, R-CMD-check and covr.
- User-facing changes get a bullet in `NEWS.md`.
- Follow the tidyverse style guide; don't restyle code unrelated to your change.

## Natural Earth

`R/naturalearth.R` opens with three data gotchas, each verified against the
data: join on `adm0_a3` and never `iso_a3`; never derive area from scale 110;
`-99` is a sentinel in numeric columns as well as code columns. Read that header
before touching the provider.
